# arcgis2noizz — בניית עולם המשחק מנתוני GIS

ממיר מצולעי בניינים, צירי כבישים ונקודות עניין מ‑ArcGIS לעולם של `noizz26.html`,
כך שהמשחק מציג את **הרחובות והבניינים האמיתיים** של אזור נתון בסגנון GTA2.

ההתנגשויות נגזרות אוטומטית ממצולעי הבניינים — אין צורך לצייר מסכת חסימה ביד.

## דרישות

Python 3.8 ומעלה. **אין תלויות** — ספריית התקן בלבד, כדי שירוץ ברשת פנימית ללא `pip install`.

## התחלה מהירה — הרצה על נתוני הדוגמה

```bash
cd tools
python3 fixtures/make_fixture.py                 # יוצר עיירה סינתטית ב-wkid 2039
python3 arcgis2noizz.py --config config.fixture.json --inject ../noizz26.html
```

פתחו את `noizz26.html` — העיר הפרוצדורלית הוחלפה בעיירה מהנתונים.
לחזרה: `git checkout noizz26.html`.

## שימוש אמיתי

```bash
cp config.example.json config.json               # ערכו את הכתובות והשדות
export NOIZZ_ARCGIS_TOKEN='…'                    # רק אם השרת דורש אימות
python3 arcgis2noizz.py --config config.json --inject ../noizz26.html
```

### שני מצבי קלט

| `source.mode` | מה קורה |
|---|---|
| `"url"` | הכלי פונה ל‑ArcGIS REST ישירות, עם עימוד ו‑`outSR` |
| `"files"` | הכלי קורא קבצי GeoJSON או Esri‑JSON שיוצאו מ‑QGIS או מ‑ArcGIS Pro |

**אם השליפה הישירה נחסמת** (token, אימות AD, חומת אש) — עברו ל‑`"files"`.
צוות ה‑GIS מייצא, אתם מזינים, התוצאה זהה.

### פרמטרים

```
--config   קובץ ההגדרות (חובה)
--out      קובץ עולם JSON                (ברירת מחדל: noizz26-world.json)
--block    קובץ עם בלוק ה-JavaScript להדבקה ידנית
--inject   נתיב ל-noizz26.html — הזרקה אוטומטית בין סימני התחום
```

`--inject` מחליף את מה שנמצא בין הסימנים `NOIZZ26-WORLD-DATA` בקובץ המשחק.
**אין למחוק את הסימנים** — בלעדיהם ההזרקה תיכשל.

## הגדרות מרכזיות

| שדה | משמעות |
|---|---|
| `source.outSR` | מערכת הקואורדינטות שתבקשו מהשרת. בישראל: **2039** (רשת ישראל החדשה). השרת מבצע את ההיטל — אין צורך בספריית projection |
| `source.bbox` | חיתוך מרחבי `[xmin,ymin,xmax,ymax]` ביחידות `outSR`. `null` = כל השכבה |
| `fields.floors` / `heightMeters` | מאיזה שדה נגזר גובה הבניין. גובה במטרים מומר לקומות לפי `metersPerFloor` |
| `fields.district` + `districtMap` | מיפוי ייעוד קרקע לאחת מארבע השכונות (0 מרכז עסקים · 1 תעשייה · 2 מגורים · 3 פארקים). ללא שדה כזה, השכונה נקבעת לפי גובה הבניין |
| `fields.roadWidthScale` | הרחבת הכבישים לצורכי משחקיות. `1.3` נותן רחוב נהיג בלי לשנות את הגאוגרפיה |
| `world.pixelsPerMeter` | **הפרמטר הכי חשוב.** ראו הטבלה למטה |
| `world.simplifyMeters` | סף פישוט מצולעים. הגדלה מקטינה את הפלט |
| `world.cellPx` | רזולוציית רשת ההתנגשות |

## ⚠️ קנה מידה מול שטח — הפשרה המרכזית

הרכב במשחק מצויר באורך קבוע של 45 פיקסלים. לכן `pixelsPerMeter` קובע גם את
יחסי הגודל וגם כמה שטח אפשר לכסות:

| פיקסל/מטר | שטח מרבי | איך זה נראה |
|---|---|---|
| 1.2 | ~2.9 ק"מ | הרכב ענק ביחס לרחוב — לא משכנע |
| **3.0** | **~1.1 ק"מ** | **יחסי GTA2. מומלץ** |
| 6.0 | ~580 מ' | רכב קטן, רחובות רחבים; מתאים לקמפוס בודד |

העולם מוגבל ל‑`maxWorldPx` (ברירת מחדל 3500) כי הרצפה מצוירת לקנבס אחד:
3500² ≈ 49MB. הכלי מקטין את קנה המידה אוטומטית ומתריע אם חרגתם.
**המלצה מעשית: בחרו `bbox` של רובע, לא של עיר שלמה.**

## מגבלות ידועות

- **חורים במצולעים** (חצרות פנימיות) מדולגים — רק הטבעת החיצונית נלקחת
- **פירוט הרחוב מצומצם**: מעברי חצייה, קווי עצירה וחצי נתיב קיימים רק בעיר
  הפרוצדורלית, כי הם מחושבים מרשת קבועה. זיהוי צמתים מצירים אמיתיים הוא
  עבודה בפני עצמה
- מצולעים מתחת ל‑`minAreaSqM` ומעל `maxBuildings` נזרקים — הדוח בסוף ההרצה
  מציין כמה וגם למה

## אבטחה

- ה‑token נקרא מ‑`NOIZZ_ARCGIS_TOKEN`. אם תשימו אותו בקובץ ההגדרות תקבלו אזהרה —
  קובץ הגדרות נוטה להגיע ל‑git
- ה‑token לעולם אינו מודפס, גם לא בהודעות שגיאה
- `config.json` ופלטי הכלי נמצאים ב‑`.gitignore` של התיקייה הזו
- הגאומטריה הנכנסת עוברת ולידציה: טיפוסים, ערכים סופיים, תקרות קודקודים ורשומות

## פתרון תקלות

| תסמין | סיבה סבירה |
|---|---|
| `ArcGIS: Invalid token` | חסר `NOIZZ_ARCGIS_TOKEN`, או שפג תוקפו |
| `לא נמצאה גאומטריה שמישה` | `where` מסנן הכול, `bbox` מחוץ לשכבה, או `outSR` שגוי |
| הבניינים במיקום מוזר | ה‑`wkid` בפועל שונה מ‑`outSR`. בדקו `<layer>?f=json` |
| הבלוק ענק | הגדילו `simplifyMeters`, הקטינו `pixelsPerMeter`, או צמצמו `bbox` |
| המשחק מציג עיר פרוצדורלית | הנתונים נדחו בוולידציה. ודאו ש‑`meta.world ≤ 6000` ושיש מערך `buildings` |
