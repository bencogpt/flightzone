# שאל את הנתונים — מוקאפ ממשק שאילתה בשפה טבעית

מוקאפ אינטראקטיבי לבחינת בעלי עניין עבור PRD גרסה 1.1 — *ממשק שאילתה בשפה טבעית לנתוני כניסה ויציאה*.

**קובץ HTML בודד, ללא Backend, ללא תלויות חיצוניות.**

## הפעלה

פתחו את `index.html` בדפדפן (Chrome / Edge). אין צורך בהתקנה, בשרת או בחיבור לרשת.

## מה יש במוקאפ

| דרישה | מימוש |
|---|---|
| F1 שאילתה בשפה טבעית | תיבת שאלה חופשית בעברית; מנוע זיהוי כוונה (כיוון, סוג מעבר, תקופה, פילוח, אדם, נקודת מעבר, אזרחות) |
| F2 דיאלוג הבהרה | 4 טריגרים — שם אירוע ללא תאריך (חובה להבהיר), תקופה עמומה, שם דו-משמעי, סוג מעבר לא מפורט; עם "דלג" וברירת מחדל מוצגת בשקיפות |
| F3 תשובה מסוכמת | 1–3 משפטים, נתון מרכזי מודגש, הקשר "X מתוך סך של Y", כרטיסי KPI |
| F4 ויזואליזציה אוטומטית | ציר זמן / עמודות / עוגה / עמודות מוערמות — נבחר לפי סוג השאלה (SVG מקומי, ללא ספריות) |
| F5 Drill-down | לחיצה על גרף או על הכפתור → טבלת רשומות גולמיות עם סינון, מיון ודפדוף; שדות רלוונטיים לשאלה בלבד |
| F6 מחוון אמינות | ✅ מלא / ⚠️ חלקי / 🔢 מחושב + טולטיפ ופירוט הפער בכרטיס התשובה |
| F7 ייצוא Excel | קובץ CSV עם BOM (נפתח ב-Excel), כותרות בעברית, שם קובץ = תאריך + תמצית השאלה |
| F8 ייצוא PDF/PPT/Word | בחירת פורמט; כולל שאלה, תמצית, גרפים, תאריך הפקה ושם משתמש |
| F9 היסטוריית שאילתות | שמירה בין סשנים (localStorage), חיפוש, סינון, שחזור בלחיצה, מועדפים, גריעה אוטומטית מעל 6 חודשים |
| F10 דו"חות מתוזמנים | תדירות (יומי/שבועי/חודשי/מותאם), נמענים מרשימה סגורה, קובץ מצורף, ניהול (עריכה/השהיה/מחיקה) + תצוגת המייל שיישלח |
| F11 שאלות ללא מענה | הודעה שמסבירה *למה* אין מענה + רישום אוטומטי בדו"ח שבועי ל-PM ולפיתוח (מסך + תצוגת מייל) |
| F12 Feedback | 👍/👎 בסוף כל תשובה, הערה חופשית ב-👎, דו"ח גולמי מקובץ לפי שאלה |
| NFR1 / NFR6 / NFR7 / NFR8 / NFR10 | מחוון זמן תגובה, מסך Audit log, ממשק RTL מלא עם תיעתוק לטיני מבודד, מדיניות שמירה, ניווט מקלדת ו-aria בגרפים |

בנוסף: מסך **מקורות ו-Schema מאוחד** (מיפוי שדות לפי מקור, N/A, פערים והתנגשויות) ומסך **מדריך הדגמה**.

## נתונים סינתטיים

הנתונים נוצרים בדפדפן בזמן הטעינה עם seed קבוע — אותם נתונים בכל טעינה, ללא קובץ נתונים חיצוני:

- ~10,200 רשומות מעבר של 2,200 אנשים, לתקופה 08/2025–08/2026
- 4 מקורות: תעופה מקומית, תעופה זרה, מעברים יבשתיים, מעברים ימיים
- שמות בעברית + תיעתוק לטיני, מותאמים לאזרחות
- פערים מדומים בכוונה כדי להדגים את מחוון האמינות: קליטה חלקית מחברות זרות ב-01–02/2026, "אזרחות" חסרה בכ-12% מהמעברים הימיים, "מטרת נסיעה" שאינה מדווחת בתעופה זרה ובמעברים ימיים, והתנגשות מקורות במעברים יבשתיים

## מסלול הדגמה מוצע

1. שאלה בסיסית — "כמה כניסות היו ביולי 2026?"
2. שאלה עמומה — "כמה אנשים נכנסו לאחרונה דרך מעברי גבול?" → שתי שאלות הבהרה, אפשר "דלג" ולראות את ברירות המחדל בשקיפות
3. לחיצה על הגרף → Drill-down → ייצוא Excel
4. "שמור כדו"ח מתוזמן" → בחירת נמענים → "תצוגת מייל" במסך הדו"חות
5. שאלה מחוץ לתחולה — "למי מהנכנסים ביוני יש עבר פלילי?" → הודעה מסבירה + רישום בדו"ח השבועי
6. החלפת פרסונה בכותרת (חוקר / אנליסטית / PM) ומסכי ניהול המוצר

## מגבלות המוקאפ

- אין Backend: אין SSO/MFA אמיתי, אין מנוע NLU מבוסס מודל, אין שליחת מייל בפועל, ואין הרשאות (מחוץ לתחולה ב-V1)
- זמני התגובה מדומים; ההפקה בפועל של PDF/PPTX/DOCX תתבצע בייצור בצד השרת (במוקאפ: PDF דרך תיבת ההדפסה, Word כקובץ `.doc`, PPT כתצוגת שקפים ב-HTML)
- המצב (היסטוריה, מועדפים, דו"חות, Feedback, Audit) נשמר ב-localStorage של הדפדפן המקומי
- שמות קבצים בעברית תלויים בהגדרות הדפדפן ומערכת ההפעלה; בסביבות עם locale מוגבל הדפדפן עשוי לשמור את הקובץ בשם `download`

## מבנה הקובץ

`index.html` מחולק לחמישה מודולים בתוך הקובץ: תשתית ונתונים סינתטיים · הבנת השאלה ומנוע השאילתות · ויזואליזציה וכרטיס תשובה · זרימת השאילתה וייצוא · מסכי ניהול ואתחול.
